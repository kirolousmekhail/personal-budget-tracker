# Personal Budget Tracker - IPO Chart

## Input

-Main menu choice (1-4)
- Income category (1-3)
- Income amount
- Expense category (1-3)
- Expense amount

## Process

-Validate the main menu choice.
-Validate the income Category.
-Validate the expense category.
-Validate that income and expense amounts are greater than or equal to 0.
-Add income to the appropriate income category.
-Add expenses to the appropriate expense category.
-Calculate total income.
-Calculate total expenses.
-Calculate net balance.
- Determine whether the user made a profit, had a loss, or broke even.

## Output

- main menu
- Income menu
- Expense menu
- Invalid input messages
- income confirmation
- Expense confirmation
- Total income
- Total expenses
- Net balance
- Financial status
- Goodbye message
